# Awesome DESIGN.md

Source: https://github.com/VoltAgent/awesome-design-md (MIT, see LICENSE).

Each folder in `design-md/<brand>/` has a `DESIGN.md` with that site's colors, type, spacing, components and layout patterns.

## How to use

1. List the brands: `ls design-md/`.
2. Read the one the user names (or the closest match to their brief): `design-md/<brand>/DESIGN.md`.
3. Build or restyle the page following that file's tokens and rules. Treat it as a reference for visual language, not as permission to copy logos or trademarks.
